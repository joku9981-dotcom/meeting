未開始

會議即時翻譯

把手機放在說話的人附近，按下「開始聆聽」。聽到的內容會一句一句翻譯，顯示在這裡。

翻譯用你自己的金鑰，只存在這個瀏覽器裡。到 Claude Console 的 Settings → API keys 建立。

選填。寫得越具體，專有名詞翻得越準。

  • iPhone 用 Safari、Android 用 Chrome 開啟這個頁面。
  • 不要連藍牙耳機：手機會改用耳機上的麥克風，收不到會議室的聲音。
  • 螢幕要保持開著。鎖定螢幕或切到其他 App 會暫停，回到這頁會自動接續。
  • 部分 Android 手機每次重新收音會有提示音，開會前先把音量調低。

語音由手機內建的辨識服務轉成文字，再用你的 API 金鑰交給 Claude 翻譯。金鑰只存在這個瀏覽器裡。機密會議請先確認公司規定。
